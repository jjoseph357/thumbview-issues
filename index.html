Thumbview Research Study: Participant Consent

University of Saskatchewan • Department of Computer Science

We are researching how software developers find and revisit code when using a spatial minimap grid instead of traditional tabs and file trees.

If you completed our demographic form, you were given a Participant ID so we can connect your programming background with your navigation patterns. You can enter that ID directly in Thumbview's settings or during the first-time prompt.

What we collect:

  • When you open Thumbview and how many seconds it takes you to pick a file
  • Which grid slot (row and column) you clicked
  • Tool usage counts, such as search, magnifier preview, and folder drill-downs
  • When you open files via Quick Open or the explorer, so we can measure how often you use spatial navigation versus standard editor tools

What we never collect:

  • Zero code or file contents
  • Zero file names or folder paths
  • Zero search queries (we only record whether you searched and how many matches appeared)

All usage records are uploaded over HTTPS to precision.usask.ca in Canada. Participation is voluntary. You can leave at any time by running Thumbview: Leave the Research Study in VS Code, which stops collection and drops any unsent records immediately.

To have your recorded data deleted from our server, send your Participant ID to us by opening an issue at https://github.com/jjoseph357/thumbview-issues.
