Thumbview Research Study: Participant Consent

Study Version 1 • Academic Research on Spatial Code Navigation

Researchers are studying how software developers locate, revisit, and navigate files in their codebase using a stable spatial minimap (Thumbview), compared to traditional file switching methods.

Participation is completely voluntary. You can join or leave the study at any time directly within VS Code by running Thumbview: Leave the Research Study. Leaving immediately stops data collection and discards any pending uploads.

1. What Data Is Collected

When you opt in and VS Code usage telemetry is enabled, Thumbview records:

  • Open Latency & Visits: When Thumbview is opened, the trigger method (F4 shortcut, Command Palette, or tab click), and how long it takes to appear.
  • Target Navigation: How long it takes to select a file, whether the selection was a direct jump, switch, or tab closure.
  • Interaction Patterns: Whether you searched, query length, number of search matches, number of tiles hovered, folder drill-ins, and use of keyboard navigation or the magnifier.
  • Spatial Coordinates: The grid slot (row and column) of the selected tile, and whether the tile remained in the same relative position since you last opened it.
  • Thumbview Actions: Specific action names performed (e.g. reordering tiles, ignoring files, reflow, toggling layout mode).
  • Navigation Share: When files are opened via other editor methods (e.g., Quick Open or Explorer) to evaluate the proportion of navigation using spatial maps.

2. What Is Never Collected

Strict Privacy Guarantee:
  • No file contents or code are ever read, transmitted, or stored.
  • No file names, folder names, or file paths are ever collected.
  • No search queries or text typed into editors is ever collected.

3. How Files Are Identified (Pseudonymous Hashing)

Files are referenced only through an irreversible, salted HMAC-SHA256 hash computed locally on your machine: HMAC-SHA256(participant_salt, workspace + relative_path). The secret salt is stored exclusively on your computer in ~/.thumbview/study.json and is never sent to the researchers or database. This allows research analysis to know if the same file was revisited without ever knowing the name or path of that file.

4. Pseudonymity & Server Logs

Data collected is pseudonymous, not anonymous:

  • Every telemetry batch carries a random UUID participant ID generated for your computer.
  • The backend database host (Supabase) sees your client IP address during HTTPS upload requests.
  • If you choose to complete the pre-study or post-study survey, your participant ID is included in the survey URL so responses can be correlated with usage trends. The survey provider will also see your responses and IP address.

5. Data Rights & Deletion

You can view and copy your participant ID at any time in VS Code via Thumbview: Research Study Info. If you wish to have all your recorded study data deleted from the study database, you can request data deletion by providing your participant ID to the study maintainers.

6. Contact & Questions

For inquiries regarding this study or data deletion requests, please open an issue or contact the maintainers at the Thumbview Issues Repository.
